# Security policy

## Supported versions

Security fixes are considered for the latest released `0.x` version. Gleiswerk
is at an early stage and must not be relied on as a safety-certified railway
control system.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
private vulnerability reporting for this repository. If that option is not
available, contact the repository owner privately through
[GitHub](https://github.com/micknudsen).

Include a clear description, affected version, reproduction steps, and the
potential impact. We will acknowledge the report, assess it, and coordinate a
fix or public disclosure where appropriate.
