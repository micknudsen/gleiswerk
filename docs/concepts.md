# Concepts

## Local first

Gleiswerk is intended to run close to the railway. Core operation must not
depend on a cloud service or a permanent internet connection.

## Operator authority

Automation assists railway operation; it does not erase the operator's
ability to understand, inspect, and stop what is happening. Future control
features will make commands, state, and safety-relevant transitions visible.

## Incremental delivery

The project begins with a reliable delivery path before adding hardware
integration. Each later capability should be small enough to test in isolation
and document with its operational assumptions.

## Compatibility

The development and package toolchain targets macOS, Linux, and Windows.
Hardware support will be specified separately as it is introduced.
