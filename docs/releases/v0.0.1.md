# Gleiswerk v0.0.1

## New capability

Gleiswerk v0.0.1 establishes the project’s installable command-line package
and reproducible Conda delivery path. Use `gleiswerk --help` and
`gleiswerk --version` after installation; the package can also be run with
`python -m gleiswerk`.

## Configuration contract

This release introduces no layout or controller configuration contract.
Gleiswerk has no configuration vocabulary yet.

## Non-goals

This release does not introduce layout modeling, controller addresses,
occupancy detection, routes, turnout commands, signals, train movement,
dispatching, simulator behavior, hardware control, or railway automation.
It establishes the delivery foundation for later, separately documented
capabilities.
