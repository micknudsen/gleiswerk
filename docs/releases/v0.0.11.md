# Gleiswerk v0.0.11

## New capability

Gleiswerk v0.0.11 adds `gleiswerk runtime-evidence diagnose`, a deterministic
offline workflow for reporting supervised runtime-evidence health, provenance,
freshness, completeness, fault state, and recovery sessions. It exercises the
same controller-independent service contract used by runtime adapters without
opening a controller connection.

## Configuration contract

Schema-v3 topology vocabulary and the Installation Binding are unchanged. The
new bounded diagnostic scenario names only logical occupancy zones and source
IDs; it does not include controller addresses, protocol frames, or endpoints.
See the [runtime evidence diagnostics workflow](https://micknudsen.github.io/gleiswerk/runtime-evidence-diagnostics/) and [logical evidence contract](https://micknudsen.github.io/gleiswerk/logical-evidence-contract/).

## Non-goals

This release does not add a live-hardware command path, connect to a
controller from the diagnostic workflow, command turnouts or signals, dispatch
trains, persist runtime state, or grant movement authority from live hardware.
