# Gleiswerk v0.0.6

## New capability

Gleiswerk v0.0.6 adds explainable, static RoutePlan compatibility analysis.
Layout authors can compare every pair of compiled routes through the core API
or the read-only `gleiswerk layout compatibility` command. Reports identify
shared exclusive claims and incompatible Control Device requirements, with
deterministic provenance that explains each result.

## Configuration contract

Compatibility analysis works with two or more immutable RoutePlans compiled
from the same validated schema-v3 topology revision. It does not introduce
new layout vocabulary or change the schema-v3 configuration contract. See the
[RoutePlan compatibility contract](https://micknudsen.github.io/gleiswerk/routeplan-compatibility-contract/)
and [layout configuration guide](https://micknudsen.github.io/gleiswerk/layout-configuration/)
for the result format, CLI workflow, and safety boundary.

## Non-goals

This release does not infer physical geometry or live clearance, reserve
resources, command Control Devices, clear signals, establish movement
authority, dispatch trains, operate the simulator, or control hardware. A
compatible result explains declared RoutePlans; it is not permission for a
train to move.
