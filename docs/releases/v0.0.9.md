# Gleiswerk v0.0.9

## New capability

Gleiswerk v0.0.9 prepares a read-only hardware-commissioning boundary for a
Märklin Central Station 3 plus (CS3+) with S88 feedback. It adds an
Installation Binding for the selected controller, a controller-specific S88
adapter that produces logical evidence, and a supervised
`gleiswerk commissioning verify` workflow that checks a fresh capture against
the configured layout and bindings. The verifier reports failures
deterministically and fails closed when its capture is incomplete, stale, or
does not match the commissioned revision or firmware.

## Configuration contract

Schema-v3 topology vocabulary is unchanged. Hardware-specific endpoint,
firmware, S88, command-channel, and position-evidence mappings belong in a
revision-matched Installation Binding. The commissioning command consumes a
fresh, firmware-pinned CS3+ capture and explicit occupancy expectations; see
the [hardware commissioning workflow](https://micknudsen.github.io/gleiswerk/commissioning-cli-workflow/),
[logical evidence contract](https://micknudsen.github.io/gleiswerk/logical-evidence-contract/),
and [schema-v3 topology contract](https://micknudsen.github.io/gleiswerk/schema-v3-topology-contract/).

## Non-goals

This release does not open a controller connection from the verifier, command
turnouts, clear signals, dispatch trains, create movement authority from live
hardware, or prove physical turnout position from a command acknowledgement.
It does not make an untested CS3 firmware, another controller, Link S88, or a
different feedback family supported. Live commissioning remains a supervised
procedure; emulator tests remain the CI authority.
